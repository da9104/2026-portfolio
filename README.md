# Dami Kang portfolio

A portfolio of tools for operations teams, covering AI agents, meeting intelligence, knowledge workflows, and practical AI education.

**[View the live portfolio](https://da9104.github.io/2026-portfolio/)**

The site is built with HTML, CSS, and JavaScript. It uses GSAP for animation and Matter.js for the footer physics. The English and Korean language selector saves visitors' preferences.

The static site is in `dist/`. Its build log reflects a snapshot through 14 November 2026; project descriptions are based on commit history.

To check the JavaScript syntax, run `npm run check`. GitHub Pages serves the `gh-pages` branch; changes to `dist/` on `main` need to be published to that branch as well.
